Adapter: built-in logic
Your folder must contain a CarController.py defining class CarController with next_move(state) returning forward / left / right / back / stop.

Python runs in the browser through Pyodide (WebAssembly) — the first load downloads the runtime, so give it a few seconds. The competition rules are enforced by the simulator: a car is held at its quadrant boundary and cannot drive through a wall.
